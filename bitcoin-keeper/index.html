Browser compatibility and source

The embedded app uses Bitcoin Keeper upstream commit 1adf4f66399a2bfac4572d9da94440323bff02f2 from its canonical sprint branch. Its React Native app, original screens, Navigator, Redux store, and wallet/QR code run through React Native Web. Browser adapters provide session-only storage, a Realm-compatible session database, camera access, and the direct QR transport. Physical-device features are unavailable in the browser. MIT license · third-party notices.

QR transfer passes encoded frames into each app’s normal camera scanner/parser path. Specter DIY remains its own firmware Worker and storage. Reset each device separately. Bitcoin balances, history, fees and broadcasting use mempool.space’s Testnet4 HTTPS API; queried script hashes and transactions are shared with that service. Private keys and simulator QR exchanges stay in your browser.
