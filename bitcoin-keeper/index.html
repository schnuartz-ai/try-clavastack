Browser compatibility and source

The Keeper code is pinned to upstream sprint commit 1adf4f6 (MIT license). Third-party notices and bundle notices are included. Its React Native app currently has no web entry point. This page uses Keeper's wallet/vault factories, address derivation, PSBT input construction, UR encode/decode and transaction parsing. Camera permission, session-only simulator storage and direct QR transport use browser adapters. Specter DIY remains its own firmware Worker and storage.

Reset Keeper clears its session state. Reset Specter test state invokes the simulator's factory reset. No wallet data or QR frames are sent to the server.
