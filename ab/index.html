Virtual USB ConnectionUse these browser simulators with a compatible desktop companion app.

Specter Virtual Host creates a local connection between this simulator and a compatible companion app, such as Specter Desktop. It runs only on your computer and uses Specter DIY's official simulator port.

Download for Windows (.exe) Download for Linux (x64) Download for macOS (Apple Silicon) Download for macOS (Intel)

Source code, releases and checksums: github.com/cryptoadvance/specter-virtual-host

  1. Download and run Specter Virtual Host for your operating system.
  2. Open both simulator devices, finish setup with a public test seed and reach Applications.
  3. Enable Device settings → Communication → USB communication.
  4. In your compatible companion app, add or rescan hardware devices. The simulator appears as Specter DIY.

Unsigned preview builds may trigger a Windows SmartScreen or macOS Gatekeeper notice. On Linux/macOS, make the downloaded file executable before running it. The bridge listens only on this computer.
