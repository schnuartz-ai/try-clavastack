ℹ️ About this simulator ▾

This is real Specter DIY firmware — the same MicroPython codebase that runs on physical Specter DIY hardware — built for its official Unix simulator target and run in an isolated, ephemeral server-side session allocated just for you.

How it works

  • Your click/tap input is sent to a dedicated simulator process on our server.
  • Its screen is streamed to your browser over noVNC (VNC-over-WebSocket) — this is a remote desktop stream, not local/offline code.
  • Nobody else shares your simulator instance while your session is active.

What's simulated vs. real

  • Real: wallet firmware logic, seed handling, PSBT parsing/signing, SD card code, QR scanner input path.
  • Simulated hardware: the touchscreen (rendered via VNC), the microSD card (backed by a per-session server folder), the QR scanner (backed by a real TCP interface the firmware itself exposes for its Unix simulator).
  • Not accurately simulated: secure element / hardware key isolation, physical tamper resistance, battery, exact touch latency — those only exist on real hardware.

Why never use a real seed

This session runs on shared server infrastructure, is not tamper-resistant, and its state can be reset or reclaimed at any time. Treat everything you enter here as public. Use a throwaway BIP39 test phrase, never a wallet you actually hold funds in.
