Browser compatibility and source

The original BlueWallet 8.0.1 React Native app runs from pinned commit 0a53056a636370073a58d6cdd6de5c0728e5926a. Its screens, navigation, wallet import and transaction algorithms come from upstream. Browser adapters provide React Native Web rendering, in-memory storage, camera, QR and shared file dialogs. MIT license · third-party notices · dependency licenses · build provenance.

This browser port is explicitly restricted to Bitcoin Testnet3 encoding and derivation. Mainnet key versions, addresses and derivation paths are rejected. It is an offline simulator: balances do not represent coins, and no transaction can be broadcast. PSBTs have no intrinsic network marker; only public synthetic transactions should be used. Standard SeedQR enters BlueWallet’s original parser. CompactSeedQR is an additional browser feature that converts QR byte-mode entropy locally into a BIP39 phrase. QR frames and images stay in the browser. USB signing, biometrics and native secure storage are unavailable.
