Browser compatibility and source

The embedded app runs Bull Bitcoin upstream commit 98eb380f74a507ce1bcb6848bd2d77cf46959f9e from its canonical develop branch. Its original Flutter screens, BLoC, GoRouter, Drift database, wallet repositories and QR parser run in the browser. The pinned native BDK and LWK Rust wallet APIs are compiled to WebAssembly. Browser adapters provide session storage, SQLite, HTTPS transport, file dialogs and QR peripherals. MIT license · third-party notices.

A fresh/reset Bull session defaults to Bitcoin Testnet3 and Liquid Testnet. Saved network choices are preserved. Blockchain synchronization uses Blockstream’s public HTTPS Esplora APIs; queried scripts and broadcast transactions are shared with that service. Custom Electrum TCP servers and Tor require a native app. QR frames pass through both applications’ original parsers. Each device has its own reset.
