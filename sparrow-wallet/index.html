Sparrow does not run in this browser

The official project describes Sparrow as a tab-based desktop wallet that does not use browser technology. The workbench below runs Specter applications; it is not Sparrow, and it does not connect to your Sparrow installation.

Official browser compatibility note ↗
TEST DATA ONLY Never enter a real seed phrase, private key, wallet backup, or transaction with real funds in the browser simulator. It is not secure hardware.

WHAT IS INSIDE THE WORKBENCH

A separate Specter device workflow

Open the workbench in a full tab ↗
01

QR and animated UR

The embedded upstream Specter Desktop and DIY apps can pass QR and animated UR frames between their own simulated screens.

02

Virtual USB cable

The cable control connects the embedded Specter Desktop app to Specter DIY firmware. It is not a USB connection to Sparrow.

03

Shared virtual media

Move the shared SD card and simulated MemoryCards into Specter DIY by dragging them. Right-click a MemoryCard to reset its simulated contents.

Sparrow stays separate. Use Sparrow's own desktop interface for wallet actions. No wallet data is passed between Sparrow and the Specter workbench on this page.
